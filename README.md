Network Monitor Dashboard

Sistema de Monitoreo de Red Empresarial orientado a la supervisión y visualización del estado de dispositivos dentro de una infraestructura de red simulada.

El proyecto permite observar en tiempo real el comportamiento de distintos dispositivos de red como routers, switches, estaciones de trabajo y servidores, mostrando métricas relacionadas con disponibilidad, latencia, rendimiento y estado general de la red.

Descripción General

Las redes empresariales modernas requieren mecanismos de supervisión constantes que permitan detectar fallos, degradación del servicio y problemas de conectividad antes de que afecten la operación de los usuarios.

Este proyecto propone una solución de monitoreo centralizado que integra:

Visualización de dispositivos de red
Supervisión del estado de conectividad
Representación gráfica de métricas
Monitoreo en tiempo real
Dashboard web interactivo
Arquitectura basada en API REST

La solución simula el comportamiento de una red empresarial mediante una topología desarrollada en Cisco Packet Tracer y una plataforma web capaz de representar visualmente el estado operativo de la infraestructura.

Objetivo del Proyecto

Diseñar e implementar una plataforma de monitoreo de red empresarial que permita supervisar dispositivos y métricas de rendimiento a través de un dashboard centralizado e interactivo.
